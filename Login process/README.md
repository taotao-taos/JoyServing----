# Login process（历史脚手架）

> **注意：** 此目录为 Google AI Studio / Gemini 早期脚手架，**未接入**主应用。  
> 主应用的登录在 `src/components/LoginPage.tsx`（Mock 认证）。  
> 请从项目根目录运行主应用，见 [../README.md](../README.md)。

## 若单独运行本子项目

1. `npm install`
2. 复制 `.env.example` → `.env.local`，设置 `GEMINI_API_KEY`
3. `npm run dev`

主项目文档：[../docs/README.md](../docs/README.md)
